# MMD Look Studio

面向 **Blender 5.2 / Eevee、MMD 人物＋场景** 的独立、可恢复渲染插件。预设由作者制作并随插件提供，用户选择后应用；没有用户预设保存或新增入口。

当前版本 **0.3.2**。版本号只由作者决定，打包脚本读取 manifest，不自动递增。

## 直接使用

1. 运行 `python3 scripts/build_package.py` 生成安装包，再从 Blender 的“从磁盘安装”选择 `output/zelda_daylight-0.3.2.zip` 并启用 **MMD Look Studio**。
2. 3D 视图按 **N → MMD Render**，选择预设。
3. 选中人物网格，点击 **应用预设**，同时应用材质、灯光和后期。
4. 头发有黑边时可点 **处理头发黑边**；参数默认折叠到高级设置。
5. 用 **恢复材质** 和 **恢复环境** 分别还原。保存重开仍能恢复，但需启用扩展。

保留旧扩展 ID `zelda_daylight` 及旧场景属性，升级不会创建第二个插件。切换预设后需点击应用；未选中的人物材质不会自动改写，场景灯光与后期则影响整个场景。原材质、贴图、UV、骨骼、动作与相机位置保留，原灯光和明确命名的几何描边默认暂时停用。

## 作者提供的预设

- **王国白昼**：暖阳、两段明暗、哑光布料、方向性头发亮带与远景空气透视。
- **冷暖逆光**：独立的柔和物理材质、金橙与蓝色侧后灯、柔和正面补光、深蓝背景、AgX 与克制辉光。头发亮带分别跟随两盏侧灯的位置、颜色、能量和渲染显隐；皮肤、服装和金属采用不同反光参数。

冷暖逆光根据所选人物的包围盒适配灯位和强度，建议只选人物，避免把大范围地形一同选入灯光定位。灯组在应用时定位；人物大幅移动、转动或更换镜头后，可恢复环境再应用以重新定位。它不自动生成原图中的建筑、水面、服装纹理或粒子。

“舞台景深”默认开启：复制当前相机数据并设置焦点与 f/5.6，不移动相机或改变焦距；恢复环境还原原相机数据。已有动画相机可以关闭此选项。原相机无景深时，背景仍需有足够距离才能形成虚化。原始背景几何继续保留，深蓝世界只出现在未被几何遮挡的背景。

冷暖逆光默认停用 MMD 的 Sphere 固定反光，避免与新灯光叠加；高级设置可重新启用。保留原 Base 颜色、Alpha、Normal，以及直接 Principled 的粗糙度／金属度贴图连接；缺少这些贴图时使用各类材质的默认值。普通 MMD 模型可得到整体灯光与反射关系，参考中的精细织物、蕾丝和金属分区仍依赖模型资产。发流亮带是艺术近似，不是完整的物理头发反射或脸部 SDF。

## 作者扩展接口

`zelda_preset/presets.py` 管理预设列表与后端注册。独立后端提供 `ensure_group()`、`update_material()`、`build_scene()`、`refresh_lights()` 和辉光配置；`stage.py` 是示例。共用材质适配和恢复机制，切换时从备份的原材质重新派生，避免层叠处理旧预设节点。新增风格应由作者添加代码和预设条目，随安装包交付。

## 头发黑边处理

默认只显示常用按钮。选择模型后点击 **处理头发黑边**，自动启用描边隐藏与细黑线修复，并按材质名自动识别头发。名称不明确或需要限定修复范围时再展开 **高级设置 → 头发黑边**。此按钮应用本预设材质，不更改场景灯光；保留原材质备份。

- **几何描边**：原有轮廓描边选项会暂时关闭命名明确的 Solidify 描边修改器。
- **独立描边材质**：开启“隐藏头发描边材质”，自动识别名称同时包含头发与描边关键词的材质。名称不明确时，在“额外描边材质”中指定原材质或本预设派生材质；同一个材质覆盖的全部面都会隐藏，因此共享脸部与头发描边时需先拆分材质。
- **画在底图里的细黑线**：开启“修复贴图黑线”。只对头发类型生效，以附近较亮且不透明的发色替换暗线，保留原图与 Alpha。默认强度 0.9、线性亮度阈值 0.03、取样半径 6 贴图像素、邻色对比 1.6。线较宽时提高半径；黑线较浅时稍增阈值。
- **修复遮罩**：白色允许修复，黑色保留原图。建议使用 Non-Color 灰度遮罩，保护刻意保留的发束分界或装饰。

这是局部颜色修复，无法重建被宽黑块遮住的细节；邻近发束、UV 岛和有意画出的深色纹理也可能被误采样。此时降低半径／强度并使用遮罩。支持直接连接的平面底图与标准 MMD Base Tex；复杂颜色节点链、UDIM 和无可读底图会保留原颜色，不插入修复。每个头发材质增加八次邻色取样，需留意大模型的渲染成本。

关闭对应选项并再次应用可以撤回，或使用“恢复选中模型材质”整体恢复。原图文件不会被覆盖。

`output/王国白昼_黑边修复演示.blend` 是本机 MMD 头部对照，使用到的底图已打包；`hair_edges_before.png` / `hair_edges_after.png` 展示隐藏独立头部描边的效果。`line_test_before.png` / `line_test_after.png` 则隔离验证贴图细线修复，均匀黑发与透明轮廓保持不变。

## 头发亮带

0.2.0 新增独立的 `ZD · Hair Toon v1` 节点组。面板里的“头发亮带”提供颜色、强度、宽度、柔边、偏移、发流方向与贴图输入，仅影响被识别或指定为“头发”的材质。默认使用模型纵向在发束表面的投影，方便现有 MMD 模型直接试用。

选择模型，保持类型“自动识别”，点“更新材质参数”升级已应用的头发材质。如果名称无法识别，可将类型设为“头发”后应用；此时选中对象的所有可转换材质都会使用头发类型，因此应先选择独立的头发对象。初始亮带强度 0.32、宽度 0.16、柔边 0.06；宽度越大，亮带覆盖越宽，偏移会改变亮带位置。关闭“启用头发亮带”再应用，会返回通用高光。

亮带读取当前观察方向，太阳方向与能量使用持久化 Blender 驱动跟随。默认优先绑定本预设太阳，也可以指定场景中的 SUN 灯。“仅应用灯光与后期”会自动重新绑定已应用的头发节点。没有太阳时亮带强度为零；切换指定太阳后再次应用。追加资产库材质后，也应再次应用以绑定当前场景太阳。

进一步细化时，将头发 UV 沿发根到发梢整理，并选择对应 U／V 方向。可选“发流贴图”将 Non-Color 的 RG 从 0..1 解码为 UV 切线平面中的方向；可选“高光遮罩”使用 Non-Color 灰度贴图，白色允许亮带、黑色隐藏亮带。留空“头发 UV”使用活动 UV。模型纵向是近似发流；弯曲发束、辫子和复杂 UV 更适合逐束整理方向贴图。底图里已经画好的固定高光会继续保留。

## 调整与兼容性

“自动识别”按材质名字猜测。脸、头发、眼睛、布料、金属和环境有不同参数；名称无法识别时，可手动选类型后应用。皮肤使用暖阴影，眼睛减弱阴影；环境使用更柔和的过渡。每个材质节点组内还可以独立调整输入。

雾距离以 Blender 单位计。默认从 12 单位开始；本机演示从 9 单位开始。大场景可增加起始距离并降低浓度。雾只影响已应用本预设的材质。

支持直接输出的 Principled 和具有标准 `Base Tex` / `Diffuse Color` 接口的 MMD Shader。未知复杂材质、纯发光或带发光贴图的材质会跳过；水、玻璃和脸部 SDF 需要另做适配。原 MMD Toon 贴图明暗由新预设替换，Base／Sphere 颜色和 Alpha 保留。

当前实测版本为 **Blender 5.2.1 LTS**。模型示例来自用户本机资产，不包含在安装包中，分享示例前应另行核对模型许可。

## 可选皮肤水渍（保持作者指定的 0.3.2）

主面板新增 **皮肤水渍** 开关。勾选后即时更新当前场景里已应用的皮肤材质，无需重新应用预设；默认关闭。开启时显示强度滑条。高级设置可选“湿润＋水珠”“湿润反光”“细小水珠”，以及密度、UV、遮罩与脸部开关。

水渍使用不规则水膜覆盖和稀疏水珠法线，增加受真实灯光影响的反光；不绘制固定白点，不覆盖原贴图。只作用于皮肤类型，默认保护脸部；材质名识别不明确时可指定类型。皮肤与衣物共用同一材质时，需要拆分或提供 Non-Color 灰度遮罩。水珠是着色法线近似，不创建真实水珠几何、流动模拟或折射体积。UV 尺寸不同会影响水珠大小；密度越高，水珠越小。

冷暖逆光还修复了中文头发名称识别、重新应用时沿用旧错误分类，以及切换／新增当前相机后未启用景深的问题。景深优先定位到变形后的脸部，存在标准头骨时跟随头部动画；自动灯组仍需按人物位置安排。

`output/冷暖逆光_水渍_女漂演示.blend` 是用户当前场景的独立副本，使用的贴图已打包；`wet_scene_before.png`、`wet_scene_improved_dry.png`、`wet_scene_improved_wet.png` 提供原效果、调整后干燥与水渍对照。用户原场景未覆盖，修改前副本位于 `output/backups/pre_wet_20261005/当前场景_修改前.blend`。

水渍通过 19 项检查，包括实际反光变化、原图与共享材质保留、轮廓 Alpha、黑色遮罩和关闭后的像素一致、脸部保护、预设切换与恢复。另通过 24 项预设检查、20 项原预设回归和 19 项黑线检查。

### 柔和动画脸（0.3.2）

冷暖逆光默认对名称包含 face／脸／顔／面部的皮肤材质添加专用脸部层：浅暖色阴影、宽柔和过渡，减少鼻颊反光与细碎阴影，保留原脸部颜色、妆容、五官和透明度。身体、独立眼睛／睫毛和衣服保持原来的材质流程。高级设置中的“柔和动画脸”即时更新，默认 0.85；设为 0 完全还原原来的舞台脸部着色。

此脸部层使用 Eevee Shader to RGB 光照探针，是参考观感的近似；没有脸部 SDF，不改变脸型或自动生成妆容。当前只按原材质名识别，脸部与衣物共享材质的模型应先拆分。参考图的发色、眼睛与面部比例由模型资产决定。

`output/face_before.png` 与 `output/face_soft_anime.png` 是相同模型、镜头、灯光的脸部近景对照，使用真实渲染；11 项脸部验证覆盖透明度、非脸部保护、水渍组合、即时更新、关闭后像素一致和材质恢复。

### 通用脸红（0.3.2）

主面板在“皮肤水渍”下方提供“脸红”开关和强度滑杆，默认关闭、开启后强度 2.2，强度范围 0～3（低于 1 为淡腮红，2～3 为浓红）；已应用人物材质时即时生效。兼容王国白昼、冷暖逆光、柔和动画脸与脸部水渍。高级设置可调整颜色、脸红高度、两颊间距、横向／纵向范围、脸部正面，以及额外脸部材质和自定义灰度遮罩。

默认根据命名脸部材质的静止网格比例生成双颊高斯晕染遮罩，使用命名网格属性传给颜色层，不依赖固定 UV 布局或模型尺寸；遮罩随蒙皮变形。保持原贴图、原 Alpha、骨骼、顶点位置和 UV，关闭后移除颜色层，恢复材质后清理自动属性。颜色乘在原贴图上，保留五官暗线。

自动识别 face／脸／顔／面部等皮肤材质，默认正面为常见 MMD 的本地 −Y，直立轴为 Z；特殊朝向可在高级设置调整。脸部未独立分材质、与衣物共图、拓扑非常稀疏或脸部比例特殊时，自动位置不能保证精确，建议指定额外脸部材质并用自定义遮罩；自定义遮罩按所选 UV 替代自动位置。共享同一网格的对象共用自动遮罩属性；若需要不同位置参数，先使网格独立或分别使用自定义遮罩。

`output/blush_before.png`／`output/blush_after.png` 是同灯光、镜头的真实脸部渲染；`output/通用脸红_女漂演示.blend` 是可直接打开的私人演示副本。更新安装仅替换本扩展文件，保留 Blender 用户偏好设置和其他插件启用状态。

脸红强度采用连续指数饱和，增加强度不会把腮红截成不透明色块；保留部分底色与光照层次。
